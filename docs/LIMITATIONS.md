# Limitations

This is a publicly deployed prototype: [canonical Worker UI/API](https://last-sentence.felix-market-radar.workers.dev), [static keyless Pages mirror](https://last-sentence.pages.dev), and [public MIT source](https://github.com/testofschool/last-sentence). As of October 31, 2026 KST, a valid replacement credential has produced real Nemotron responses and the protected Worker API is enabled. Default replay still uses recorded observations or synthetic fixtures with authored text unless connected generation is selected. The two earlier HTTP 401 smokes remain historical failures. Actual rider use, browser TTS and door timing remain unvalidated. The reduced comparison visited all17 planned slots, with16 scored and1 retained model-output failure. It is not an all-success result; sentence-replan missed±30seconds in all5 scored cases.

| Area | Boundary |
| --- | --- |
| Arrival | Seoul position records expose station/status and provider receipt time. They do not timestamp doors opening. Recorded arrival is a station-arrival proxy, with polling and provider delay. |
| Timing | Silent replay uses a virtual clock and estimated sentence durations. An audio `end` event, when available, measures browser speech completion, which is still different from doors opening. Speed changes and seeking invalidate a continuous audio timing measurement. |
| ETA | The service requires a completed recording and the registered held-out median-error gate, with at least ten windows and two train identities. Windows overlap and are not independent samples. This is an experimental readiness check, not a confidence interval or an error guarantee. Unknown routes remain unavailable; unseen directed segments disclose a line-median fallback. |
| Data coverage | Actual line-2, line-5 and line-7 sample observations have separate raw files and completeness metadata. The recorded manifest retains per-journey provenance and never fills missing stations with fixtures. Full node topology is not full empirical coverage; each line has a separate quality gate. No other lines are supported. |
| Operating period | Only late-morning October 30, 2026 KST data was recorded: line 2 from 10:02–10:42, lines 5/7 from 10:49–11:29. Rush-hour, weekend and disrupted-service performance is unmeasured. The daytime proxy validation cannot establish those operating conditions. |
| Seoul quota | The official guide states a 1,000-request daily real-time cap. The prepared Worker reserves up to 950 upstream requests per KST day using an atomic counter, then forces replay. A shared key's other applications or local recorders also consume its quota; this app cannot count those requests. |
| Sample key | The current sample call requests at most five trains. Results can change identity between polls and cannot reliably follow every train. |
| Data page | The October 30 HTML includes: “해당 데이터는 종료된 서비스입니다”. Separately, the sample endpoint returned fresh position records. A source-page banner is retained as a service-availability risk; no guarantee of continuity is made. |
| Language | Ultra's supported-language list includes Korean; omission from another card does not prove inability. One controlled same-scene request per Super/Ultra produced six inspected lines, all within 40 Unicode characters. This is mechanical 6/6 evidence only, not Korean quality, general obedience or a model ranking. |
| Speech | Web Speech voices, pronunciation, speed and lifecycle vary by browser/device. No suitable voice means text-only mode. No Korean voice must not silently become a Korean-language quality result. |
| Background use | Keep the screen open and the page active. Wake Lock is best effort, requires a supported secure context and can be released by the browser. This build does not implement geolocation; background restrictions are not attributed to geolocation. |
| Inference | Real responses with requested/provider identities and usage have been recorded. Validation failures remain failures, including a Writer station-ending rejection in reduced attempt 06. Tool, JSON-fallback and Writer behavior must be read per actual receipt; a successful smoke or configured status does not prove a completed story comparison. Tavily remains UNRUN. |
| Cost | The user cap is $3 total: $0.002961 conservative direct-smoke reserve plus the deployed $2.997039 Worker reservation ceiling. The same Durable Object ledger is retained. Known usage/catalog estimates are not an invoice; the two earlier 401 smokes and an interrupted attempt-05 dispatch have unreturned cost/usage and are not replaced by zero. The final known usage/catalog subtotal is$0.01405146 across93 responses; overall invoice cost remains unknown. |
| Comparison | Full 30×3+pair is UNRUN because the before-19:30 condition was missed. Reduced07 visited17/17 slots, with16 scored and1 unscored model-output rejection;4/5 windows are fully paired. Sentence-replan0/5 within±30seconds does not establish improvement. Fixed Unicode character-rate timing plus measured HTTP latency is simulation; failed/unscored or missing-receipt attempts do not receive invented landing errors. |
| Live mode | The prepared controller requires selection of the actual train/direction, a fresh server-verified arrival-status anchor and an eligible forward exit. Each line requires its own completed-recording quality gate. Initial estimates cover 3–10 station segments: line-2 main loop, line-5 directed branch toward the verified train terminus, or line-7 ordered path. Unknown station IDs or ambiguous termini are refused. The last 1–2 segments are outside that evaluated horizon and remain experimental. Actual live narration, rider operation and model/TTS landing performance have not been field-tested. |
| Worker transport | The public HTTP sample worked, while a separate HTTPS probe timed out after 20 seconds. Only the published SAMPLE key may use the bounded HTTP fallback; each upstream attempt consumes quota. Private Seoul keys are restricted to HTTPS, whose reachability remains unverified here. |
| Audience | No rider interviews, demand test, accessibility study or field validation was performed. Avoid relying on this prototype as an exit alarm. |
